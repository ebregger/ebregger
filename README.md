# Edison Bregger

I'm a B.S. in Mechatronics (IME) student at Michigan Technological University, expecting to graduate in May 2028. I enjoy CAD, 3D printing, machining, and building practical hardware.

## Selected mechanical work

- **[FormD T1 travel kit for the Zotac RTX 5070 SOLID](https://www.printables.com/model/1615637-formd-t1-travel-kit-for-zotac-rtx-5070-solid)** — my original, printed design for supporting this GPU in a FormD T1 case, inspired by FormD's metal travel kits for other cards.
- **3D printer modifications** — modified pin joints, printer-sized wiring channels, and a dial-indicator mount.
- **Jukebox CAD model** — an original decorative assembly made to practice complex modeling; it was never physically built.
- **2023 SkillsUSA Technical Drafting** — bronze medal at the Michigan State Championships; modeled a Rabbit corkscrew and prepared manufacturing drawings in a timed event where the full set was not expected to be completed.
